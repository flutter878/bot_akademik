# Chatbot Layanan Akademik - Prototipe

Contoh kode awal untuk **mulai dikerjakan sekarang**, bukan bukti pengerjaan pada 14-19 Oktober.

## Menjalankan
1. Instal Python 3.10+
2. Buka terminal pada folder ini
3. `python -m venv .venv`
4. Aktifkan virtual environment (`.venv\Scripts\activate` di Windows atau `source .venv/bin/activate` di macOS/Linux)
5. `pip install -r requirements.txt`
6. `python app.py`
7. Buka `http://127.0.0.1:5000`

FAQ di `faq.json` hanyalah contoh, bukan kebijakan resmi kampus. Ubah dan verifikasi sebelum dipakai. Algoritma TF-IDF bukan pemahaman bahasa yang mendalam; prototipe ini cocok sebagai baseline NLP sederhana.
